# PetHaven — Corrected VS Code Project

This version fixes the breed-image problems in the previous project.

## Image fixes
- Bruno uses a verified St. Bernard image.
- Max uses a verified German Shepherd image.
- Buddy uses a verified Golden Retriever image.
- Daisy uses a verified Labrador Retriever image.
- Storm uses a verified Siberian Husky image.
- Coco (dog) uses a verified Standard Poodle image.
- Other pets use breed/species-specific Wikimedia Commons files.
- Images use stable Wikimedia direct/redirect URLs instead of random pet APIs.
- If an image source is temporarily unavailable, the page automatically tries a second source and then shows a clean breed-specific fallback instead of a broken-image icon.

## Run
1. Open this folder in VS Code.
2. Install/use Live Server.
3. Right-click `index.html` → **Open with Live Server**.
4. Keep internet access enabled because the verified pet photographs are loaded from Wikimedia Commons.
